# File Naming Convention
## AU Partner Visa 820/801 — Pratik & Passang

All files saved to this project must follow this convention.
These documents may be reviewed by a Department of Home Affairs case officer.

---

## FORMAT

```
[FolderCode]_[DocumentDescription]_[DateIfRelevant].pdf
```

### Rules
- Use underscores `_` not spaces or hyphens
- Dates in format: `DDMmmYYYY` (e.g. `07Apr2026`) or `MmmYYYY` (e.g. `Apr2026`)
- All files should be PDF unless otherwise noted (photos: .jpg)
- No special characters except underscores
- Keep names descriptive but concise

## PHOTO NAMING (Folder 03)

Photos in the chronological bundle should be named:

```
YYYYMMDD_[Location or Occasion].jpg
```

Examples:
- `20250315_Cafe_Together_Melbourne.jpg`
- `20250601_Mickleham_Family_Lunch.jpg`
- `20260312_Cultural_Wedding_Ceremony.jpg`
- `20260322_Legal_Wedding_Old_Treasury.jpg`

This ensures photos sort chronologically in any file explorer.

---

## MULTI-PAGE DOCUMENTS

For documents with multiple pages (e.g. bank statements), compile into a single PDF.
Name the PDF with the date range:

```
10_FIN_GoalSaver_Joint_Jul2025_Jun2026.pdf
```

---

## VERSIONS

If a document has multiple versions (e.g. relationship statement drafts):

```
12_STAT_Pratik_RelationshipStatement_V2_Apr2026.pdf
12_STAT_Pratik_RelationshipStatement_FINAL.pdf
```

Always submit the **FINAL** version. Keep drafts in a `_DRAFTS` subfolder.
