MiroFish — Local Setup Guide

MiroFish is an AI-powered agent with persistent memory, combining an OpenAI-compatible LLM with Zep Cloud for long-term context.

Prerequisites

  • Node.js (for the frontend & setup scripts)
  • Python 3.10+
  • Git
  • Two API keys (both have free tiers):
    • An OpenAI-compatible LLM — recommended: Qwen-plus via Alibaba Bailian
    • Zep Cloud for agent memory — app.getzep.com

1. Clone the Repository

git clone https://github.com/666ghj/MiroFish.git
cd MiroFish

2. Configure Environment Variables

cp .env.example .env

Open .env and fill in your keys:

LLM_API_KEY=your_api_key
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_MODEL_NAME=qwen-plus

ZEP_API_KEY=your_zep_api_key

3. Install Dependencies

npm run setup:all

This installs Node dependencies, creates a Python virtual environment, and installs Python dependencies automatically.

4. Run the App

npm run dev
  • Frontend → http://localhost:3000
  • Backend API → http://localhost:5001
Note: Developed and tested on macOS. Windows compatibility is still being tested — use WSL2 on Windows for best results.
